审核时重点核对：

1. 公司、年份、指标和“结合年报解释”的任务类型是否正确；
2. `actual_intent` 与 `actual_tools` 是否完成财务事实查询、变化分析和年报检索；

5. `actual_answer` 是否先准确陈述结构化数据，再谨慎表达年报依据，避免把年报中的并列现象扩写成确定因果关系；

每行按 CSV 末尾的 12 个字段填写。无图表字段填 `NA`；引用相关性填 `1` 至 `5`，引用支持性填 `0` 或 `1`；其他布尔字段填 `0`、`1`，评分填 `1` 至 `5`，状态填 `approved`、`needs_revision` 或 `rejected`。审核备注应记录引用不足、页码/片段不匹配或回答越界的位置，不要只写“有问题”。
