# 数据与内容许可说明

## 代码

除非文件中另有说明，源代码按仓库根目录 `LICENSE`（MIT）发布。

## 不自动随 MIT 许可发布的内容

代码许可**不等于**数据许可。下列内容可能来自竞赛主办方、上市公司公告、交易所、券商研报或其他第三方，必须分别确认再分发权：

- `资料待放入/` 中的原始竞赛附件、年报和研报；
- 原始 PDF、图片及大段原文；
- `data/rag.sqlite3` 中由年报原文切分得到的文本；
- 其他由第三方材料生成、仍可能包含可识别原文的中间产物。

因此这些内容在公开发布前默认排除。公开仓库不能暗示其受到 MIT 许可覆盖。

## 结构化财务事实和评测数据

`data/finance_insight.sqlite3`、候选 CSV、评测标签及报告是否可公开，取决于竞赛规则、数据来源条款和使用范围。维护者应在发布前完成来源清单与授权核对。未核对完成时，建议仅发布 schema、导入脚本、自动评测问题和少量自行构造/脱敏样例。


## 公开合成 Demo

`scripts/init_demo_data.py` 生成的财务数值和经营说明均为项目自行构造的虚构内容，不复制第三方财报原文。它沿用公司名称与股票代码仅用于兼容现有意图解析和演示问题，但所有事实标记为 `synthetic_demo_only`，文档标题与正文也明确标记“非真实年报”。这些数据只用于软件测试和功能展示，不得视为真实财务资料或投资依据。

## 推荐发布方式

1. 公开仓库：源代码、schema、文档、测试、评测框架和合成样例；
2. 获得明确许可的数据：在本文件中记录来源、版本、授权条款和下载方式后再发布；
3. 不能再分发的数据：提供用户自行下载/放置/构建索引的说明，不上传文件本身；
4. 本机迁移用数据库和资料包：仅通过私有、受控渠道传输，不放入公开 Git 历史。
