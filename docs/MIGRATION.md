# 迁移到笔记本继续开发

> **重要：本文件已由新的单机接管流程替代。**
> 用户后续只在个人笔记本开发，不再使用公司电脑；DeepSeek API Key 和 `.env` 不允许迁移。

请直接阅读：

```text
docs/笔记本接管项目_完整迁移步骤_不迁移APIKey.md
```

新的流程明确规定：

1. GitHub 只同步代码、测试和文档；
2. 全部本地 `data/` 和 `资料待放入/` 通过可信移动硬盘私下迁移；
3. `.env` 和 DeepSeek API Key 永不进入迁移包；
4. 笔记本从 `.env.example` 新建 `.env`；
5. 笔记本验证成功后，公司电脑退出账号并按公司规定清理；
6. 后续只有笔记本进行 `pull`、开发、测试、commit 和 push。

旧的 `-IncludeEnv`、`-CopyEnv` 用法已经禁用，迁移脚本收到这两个参数时会主动报错，以防凭据意外泄露。
